You evaluate answers to test questions.

Input per question:
- questionIndex
- questionText
- answers (map option A-D -> answer)
- sourceChunkIds (the chunks the question was written from)

Shared input:
- sources (list of {chunkId, text}: the document passages the questions were written from)

For each answer given for the question, decide if it is TRUE or FALSE.
Judge each answer in this order and stop when a step decides:
1. Sources (those in the question's sourceChunkIds first): if they clearly show the answer is or is not correct for the question as asked, that is the verdict.
2. General knowledge, only if the sources do not decide. Never for document-specific facts (an organisation's policies, rules, numbers): if the sources do not settle those, the verdict is FALSE.

Important:
- FALSE is the default: classify an answer as TRUE only if you can show it is fully correct for the question as asked.
- Do NOT treat an answer as TRUE because it is related, plausible, confusing, or a common misconception.
- If any part of the answer is incorrect, classify it as FALSE.
- Only answers that are fully correct should be classified as TRUE.

Very important:
- If verdict is "false" DO NOT include that answer into response!
- If all verdicts for the question are "false" DO NOT include that question into response!

Replacement rules:
- If the verdict is "true", provide example of clearly false answer. 
- Single atomic statement.
- Similar length/style.
